# Bridge Path 디자인 시스템 (MASTER)

기준일: 2026-10-28. 무드 레퍼런스(ITSUA 스튜디오 사이트)의 구조와, 대표님이 고른 사진의 파란 팔레트를 합친 방향입니다.
`ui-ux-pro-max` 스킬의 Flat Design 스타일 + 모노 라벨 타이포를 근거로 했고, 스킬이 추천한 네이비·금색 팔레트는 쓰지 않습니다.

## 방향
**기술 사양서(spec sheet)** 느낌의 직각·격자 레이아웃 + 파랑 한 가지 포인트. 신규 제작(OEM/ODM) 견적 사이트이며 수리/AS처럼 보이면 안 됩니다.

## 적용 범위
홈 → 견적 허브(`estimate.html`) → 견적 폼 3종과 `other-inquiry` → 결과·내 견적(`my-quotes`) → `login.html` 순서. 페이지별 예외는 `pages/<page>.md`에 둡니다.

2026-11-10: 위 페이지 전부에 적용했습니다. 토큰은 두 곳에 있습니다. 홈은 `home.css`(테스트가 값을 읽음), 나머지 페이지는 모두 `style.css`를 먼저 불러 그 토큰을 씁니다. 값을 바꿀 때는 두 파일을 함께 고칩니다.
홈 외 페이지의 상단 바는 로고 이미지 대신 글자 "Bridge Path"를 씁니다(`front:files`가 루트 폴더 밖의 파일을 허용하지 않기 때문). 제품 종류 카드의 이모지는 없애고 `[ 01 ]` 모노 번호로 바꿨습니다.

틴트 위에서도 대비 4.5:1 이상인지 구현 때 확인합니다.

### 모양
- 모서리 `border-radius: 0`. 그림자·그라데이션 없음.
- 구획은 1px `--line` 선. 포커스는 `:focus-visible` outline 2px `--blue`, offset 2px.
- hover는 선 색, 배경 채움, 화살표 이동으로만(150–200ms ease). `prefers-reduced-motion`에서는 전환 제거.

### 타이포
- 라벨: JetBrains Mono 400, 12–14px, 대문자, letter-spacing 0.04em. 영문만 사용(`§ 01 — PROCESS`, `[ 01 ] ESTIMATE`, `STEP 03 / 05`).
- 본문·헤드라인: Pretendard(자체 호스팅). 헤드라인은 `clamp()`로 크게, 굵기 대비로 위계. `word-break: keep-all`.
- 본문 16px 이상, line-height 1.6, 한 줄 한글 35–45자 이내.
- 숫자는 `font-variant-numeric: tabular-nums`.

### 간격
4px 단위. 섹션 간격 96 / 64 / 48, 셀 안쪽 24 / 16. 컨테이너 최대 폭 1200px, 좌우 여백 모바일 16px.

### 반응형
기존 구간 유지: 1100px(3열), 900px(1열), 520px(모바일). 375px에서 가로 스크롤 없음.

## 레이아웃 패턴
- 섹션 머리: 모노 라벨(`§ 0N — NAME`) + 큰 헤드라인 + 오른쪽 보조 설명.
- 사실 정보 띠: 숫자/값 + 모노 캡션을 5칸 격자로. **실제 값만** 사용(통계 과장 금지). 값은 `pricing-and-launch-decisions` 기준으로 확인 후 입력.
- 진행 단계: 번호 셀을 선으로 이어 붙인 표 형태.
- 견적 폼: 상단에 `STEP 0N / 02` 모노 표기, 필드 그룹은 선으로 구획, 라벨은 항상 보이게(placeholder 대체 금지).
