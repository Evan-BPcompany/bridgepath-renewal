# FINDER GREEN 디자인 시스템 (MASTER)

기준일: 2026-11-11. 레이아웃은 2026-11-10의 것(흰 패널, 큰 선택 카드)이고, **색과 로고는 2026-11-11에 사용자가 넣어 준 FINDER GREEN 로고 키트(`finder-green-logo-kit.zip`)를 기준으로** 바꿨습니다. 그 전의 검정·주황(2026-11-10), 로고 파랑(2026-10-28)은 쓰지 않습니다.
참고 화면의 레이아웃·여백·글자 크기·카드·버튼만 참고했고, 그 서비스의 이름·로고·문구·화면 이미지는 쓰지 않습니다.

## 방향
**Pine 글자와 Pine 버튼, Ivory 바탕 위의 흰 패널, 옅은 Sage.** 키트의 색은 이 세 가지뿐이고(절제된·전문적인·세심한), 다른 강조색을 섞지 않습니다. 테두리와 장식을 줄이고 여백·정렬·글자 크기로 중요도를 나눕니다.
2026-11-11부터 이 사이트는 **골프용품 소싱 에이전트**(골프 선글라스, 골프화, 골프티)이고, 서비스 이름은 **FINDER GREEN · 파인더그린**입니다(운영 회사는 Bridge Path). 수리/AS처럼, 또는 직접 제조하는 것처럼 보이면 안 됩니다(`AGENTS.md` "서비스 방향").

- 버튼은 모두 Pine입니다. `--accent`(주요 행동과 작은 강조: 홈의 견적 시작 버튼, `#nextBtn2`, 기타 문의의 제출 버튼, 단계 번호, 결과 화면의 총 예산, "AI 추정" 표시, 포커스 링)도 지금은 Pine과 같은 값입니다. 토큰 이름은 남겨 두었으므로, 주요 행동만 다른 색으로 띄우고 싶어지면 `--accent` 한 줄만 바꾸면 됩니다.
- 보조 버튼은 흰 바탕에 선. 선택된 카드와 옅은 배경은 Sage를 푼 `--accent-soft`.
- Sage(`--sage`)는 글자색으로 쓰지 않습니다(흰 바탕 2.2:1). `homePage.dom.test.ts`가 확인합니다.
- **색 역할(홈, 2026-11-13, 사용자가 A안 선택)**: Pine = 브랜드 면·주요 CTA(제품 판, 마무리 띠, 버튼, 단계 노드). 아이보리 = 기본 바탕(Hero, MOQ, 문의 안내). 세이지 워시(`--accent-soft`) = 제작 과정 섹션 전체 배경과 문의 안내의 선택 상태(활성 항목·활성 탭), 단계 패널과 문의 예시 카드는 흰색. **골드(`--gold` `#7d5f18`)는 MOQ의 "협의 예시" 숫자와 거기로 내려가는 연결선·화살표에만** 씁니다(아이보리 위 5.3:1, 배경·본문 글자 금지, Pine 위 사용 금지). 파랑·보라·형광 금지. 테라코타는 AI 생성 페이지에서 흔한 색이라 쓰지 않습니다. 같은 배경이 이웃하지 않게(제작 과정 세이지, MOQ·문의 안내 아이보리는 가는 선 하나로 나눔). 글자색 `--ink`를 딥 잉크(`#0e2a24`)로 분리하는 안은 보류.
- 로고는 로고 키트(`finder-green-logo-kit.zip`)의 파일을 그대로 씁니다: 상단 바에는 F 심볼(`assets/logo/finder-green-symbol-green.svg`, 40px 상자 안에서 글자 높이 30px)과 글자 "FINDER GREEN", 홈 마무리 띠에는 흰색 기본형(`finder-green-signature-white.svg`, 폭 180px 이상), 브라우저 탭에는 작은 크기 전용 도안(`favicon.svg`, `favicon.ico`, `apple-touch-icon.png`). 가로형 로고는 폭 240px 이상에서만 쓰라고 되어 있어 상단 바에는 쓰지 않습니다. 비율·색을 바꾸거나 그림자·테두리를 붙이지 않습니다.
- 사이트 전체가 키트의 Pine·Ivory·Sage를 씁니다. 홈 마무리 띠는 Pine, 그 아래 푸터는 한 단계 어두운 Pine(`--ink-strong`)입니다.

## 글자와 모양 (2026-11-11, 키트 시안 기준)
- **글꼴은 Pretendard를 자체 호스팅합니다**(2026-11-13): `assets/fonts/`의 KS X 1001 한글 + 라틴 서브셋 3종(400·500·600)과 라이선스 `Pretendard-OFL.txt`. `style.css`의 `@font-face`에서 `swap`으로 불러오고, 서브셋에 없는 글자는 `--font`의 다음 글꼴(Noto Sans KR, 맑은 고딕 등)로 대체됩니다. 다른 호스트의 글꼴은 쓰지 않습니다(테스트가 막음). 새 굵기가 필요하면 같은 폴더에 파일을 추가하고 `@font-face`를 더합니다.
- **모서리는 각지게**: 패널, 카드, 입력창, 버튼 모두 2px. 알약 모양(`999px`) 버튼은 쓰지 않습니다. 둥근 것은 홈 첫 화면의 옅은 배경 번짐과 "분석 중" 회전 표시뿐입니다.
- **큰 제목은 얇게**: 홈의 h1, 섹션 제목, 마무리 띠 제목, 큰 숫자는 굵기 400. 패널 안의 제목(1.2~1.45rem)은 500.
- **이름·라벨·버튼은 한 단계만 굵게**: 카드 이름, 작은 제목, 입력 라벨, 폼 버튼은 600. 상단 바와 홈의 큰 버튼은 500. 700·800은 쓰지 않습니다.
- 홈 슬로건 앞의 표시는 로고 F의 떨어진 가로획처럼 작은 사각형입니다.

## 공용 부품
- **상단 바**(`.site-bar`): F 심볼 + "FINDER GREEN", 링크, Pine 버튼 "AI 가상견적 받기". 720px 이하에서는 `.nav-wide` 링크를 숨기고, 420px 이하에서는 버튼 문구가 "견적 받기"로 줄어듭니다. 로그인 계열 페이지는 같은 모양의 `.auth-header`.
- **패널**(`.flow` > `.panel` > `.panel-head` + `.panel-body`): 견적 흐름은 최대 폭 760px의 흰 패널 하나(선글라스 결과 화면만 1100px). 패널 머리에 뒤로 가기(링크)와 제목.
- **단계 표시**: `Step 01 제품 선택`(`.step-tag`) 또는 `01 이름 — 02 이름 — 03 이름`(`.step-indicator`). 현재 단계 번호만 Pine(나머지는 `--ink-soft`).
- **큰 선택 카드**(`.pick-grid` > `.pick`): 제품 3종(허브, `.pick-three`로 3열, 720px 이하 1열), 시작 방법 2가지(견적 폼 1단계, 2열, 560px 이하 1열). 카드가 아닌 길(다른 골프용품 문의)은 카드 아래 한 줄 링크(`.more-link`, 홈은 `.choices-more`).
- 입력창·버튼 높이는 48~52px, 눌러서 쓰는 것은 44px 이상. 포커스는 `:focus-visible` Pine 3px.

## 견적 흐름
제품 선택(홈 또는 허브) → 종류 선택과 **시작 방법**("참고 이미지가 있어요" / "이미지 없이 직접 입력할게요") → 사양 확인·보완 → 결과(선글라스) 또는 가격 범위(신발·골프티) → 고객 정보.
- 시작 방법은 `body[data-input-mode]`에만 남고(`estimate-common.js`), 2단계에서 업로드 영역을 먼저 보일지만 정합니다. 직접 입력을 골라도 이미 올린 파일이 있으면 업로드 영역은 계속 보입니다. 2단계에서 서로 바꿀 수 있습니다.
- 사진 AI 분석은 **선글라스만** 있습니다. 신발·골프티의 "참고 이미지"는 요청에 첨부만 되고, 카드에 그렇게 적혀 있습니다.
- 분석이 채운 선택 항목에는 "AI 추정 · 수정 가능" 표시가 붙고, 사용자가 값을 바꾸면 사라집니다(`data-ai-filled`).
- 분석 상태 줄은 `data-state`(`busy` / `done` / `error`)로 모양이 나뉩니다. 문구가 같은 내용을 말합니다(색만으로 전달하지 않음).
- 로그인 안내: 로그인 없이 예상 가격 범위 확인과 견적 요청 접수까지. 담당자 상세견적 요청과 내 견적은 로그인 필요.

### AI로 만든 에셋의 규칙 (2026-11-13)
- 영상은 한 번 재생하고 마지막 프레임에서 멈춥니다(반복 없음, `autoplay` 속성 없음, `preload="none"`). 모션 줄이기 방문자와 스크립트가 꺼진 경우에는 포스터만 보입니다. 글자 뒤의 Ivory 막은 글이 있는 쪽에만 둡니다.
- 제품 행의 작은 사진 3장(`assets/media/choice-*.webp`, 사용자가 직접 넣은 원본 PNG 3장을 288×216 webp로 줄인 것)은 분위기 컷이고 `alt=""`입니다. 실제 제품·품질을 보여 주는 사진처럼 쓰지 않습니다. 제품에 로고·글자·엠블럼이 생기면 쓰지 않고 다시 만듭니다.
- 제작 과정의 단계 사진 5장(`assets/media/process-*.webp`, 960×720)은 BAZE로 만든 AI 분위기 컷입니다. 공통 프롬프트(작업대, 창 낮빛, Pine·Sage만, 글자·로고·사람 없음)는 `scrollcraft/art-direction.json` 하나로 관리하고, 단계 패널 안에서 글과 함께 바뀝니다. 설명 alt가 있고 lazy입니다. 게이트웨이 "AI" 배지는 자르지 않았습니다(표시 의무 확인 전).
- **제작 과정 문구(2026-11-13)**: 왼쪽 단계 설명은 2줄 이내, 오른쪽 카드는 "제목 + 짧은 설명 + 라벨·문장 3행"입니다. 01에는 "AI 가상견적은 시작 단계이고, 견적이 제공되지 않는 제품도 요청 접수 후 담당 에이전트가 제작 조건과 가격을 확인해 안내"가 들어 있고, 생산 시작 기준은 "최종 샘플의 최종 컨펌", 일정은 "제조국·시즌·공장 상황에 따른 변동 가능성을 사전에 안내", 무역 업무는 "지원"까지만 씁니다(**"대행"은 회사가 실제로 대행하는 범위가 확인된 뒤에만**; 테스트가 막음). 사진은 패널 높이가 남는 만큼 커집니다.
- **견적 시작 화면(`estimate.html`, 2026-11-13)**: 홈과 같은 말을 씁니다. 제목 "빠른 AI 가상견적이 가능한 대표 품목", 카드마다 견적 방식 라벨("AI 가상견적", 세 제품 모두: 골프화·골프티는 `estimate-market-preview.js`로 재질과 수량에서 예상 범위를 보여 주고 서버가 `previewShoes`로 계산함. 골프화 페이지의 옛 안내와 홈 문의 안내의 "골프화는 담당자가 가격 확인"은 11-13에 코드에 맞게 고쳤습니다기)와 실제 동작에 맞춘 한 줄 설명, 카드 아래에 세이지 박스 "그 외 골프용품도 소싱 가능합니다."(골프모자·골프장갑·볼마커·볼타월, AI 견적 없이 담당 에이전트가 확인, 버튼 "다른 골프용품 소싱 문의" → `other-inquiry.html`). 최소 주문 수량 문구는 이 화면에서 뺐습니다. 골프채·골프공 취급 여부는 사실 확인 전이라 쓰지 않습니다. 테스트: `estimateHub.dom.test.ts`.

## 홈의 구성과 모션 (2026-11-12 Hallmark 재디자인 이후, `home.css` 첫머리 주석에 이유가 있음)
순서: 첫 화면 → 진행 과정(스테퍼) → 수치 3칸 → 문의 안내(샘플 전환) → 마무리 띠 → 푸터. 컨테이너는 1120px 하나입니다.
- **첫 화면**: 왼쪽에 슬로건 제목("골프 아이디어를 필드까지"), 소개 한 줄, 시작 버튼. 오른쪽은 Pine 판(질문 + 제품 3종 행 + 큰 글자). 판 뒤의 연한 원은 스크롤에 따라 천천히 내려가며 커집니다(`.hero::before`는 이 페이지의 유일한 둥근 도형이고 테스트가 지킴).
- **파인더 링**: 제품 행에 마우스·포커스가 닿으면 링이 그 행의 화살표 둘레로 미끄러져 옵니다. 큰 글자도 같이 바뀝니다(`home.js`).
- **진행 과정 스테퍼**: 5단계 목록 + 패널. 보이는 단계의 선이 5초에 걸쳐 차고 다음 단계로 넘어갑니다. 한 번 지나가면 멈추고(반복 없음), 마우스·포커스에서 멈추며 "자동 넘김 멈춤" 버튼이 있습니다. 모션 줄이기 방문자에게는 자동 진행이 없습니다. 트랙 위의 공은 보이는 단계로 이동하고 마지막에 홀에 들어갑니다.
- **최소 주문 수량 협의 섹션**("공장이 정한 최소 수량보다, 현실적인 시작 수량으로 협의합니다", 2026-11-13 사용자 지시로 막대 그래프를 버리고 다시 설계): 제품별 협의 사례 3개(사진, 공장 기본 수량의 옅은 숫자, "기본보다 N 적게"를 말하는 화살표 선, 큰 Pine 숫자 "협의 예시"). 데스크톱은 3칸이 계단처럼 내려가고, 900px 이하는 가로 스냅 스크롤(다음 카드가 보임). 수치는 사용자가 준 것만: 골프화 1,200→500켤레, 골프티 5,000→1,000패키지(1패키지는 50개입), 골프 선글라스 2,000→800개이고, 차이(700, 4,000, 1,200)는 뺄셈입니다. 확정 수량이 아니라 "협의 예시"이며 "제품, 소재, 사양, 공장 조건에 따라 달라지고 견적에서 확정됩니다"를 섹션 끝에 유지합니다("보장·항상·무조건" 금지, 테스트가 막음). 사진 3장은 사용자가 넣은 대체 이미지의 720×540 webp(`assets/media/moq-*.webp`, 설명 alt, lazy)이고 이미지 API는 호출하지 않았습니다. 이 수량은 이 섹션에서만 말합니다. 눈썹 문구는 Hallmark F54·impeccable 금지라 뺐고, 사진 호버 확대도 Hallmark 11 때문에 넣지 않았습니다(호버에서는 옅은 기본 수량이 물러남).
- **문의 안내**: 세 가지 방법 옆에 샘플 패널(탭 버튼 3개). 탭 또는 목록 위 마우스가 샘플을 바꿉니다. 900px 이하(모바일)에서는 샘플 패널을 숨기고 세 가지 방법의 글만 보입니다.
- **움직임 규칙**: `transform`과 `opacity`만. 반복(루프) 없음. `style.css`의 `prefers-reduced-motion` 규칙은 움직임을 끝 상태로 보이고 색·투명도 변화만 남깁니다("끄지 않고 줄이기"). 홈은 그 방문자에게 제자리 페이드를 보여 주고, 스크립트가 꺼져도 내용은 보입니다(숨김 상태는 `.js-stepper`, `.js-guide` 아래에만).
- **문구 톤**: 목록·한 줄 설명은 동사 없이 끝나는 명사형, 설명 문장과 면책은 "~합니다". "~해요"체는 쓰지 않습니다. 동의서·약관은 건드리지 않습니다.
- 테스트: `homePage.dom.test.ts`(스테퍼, 링, 수치, 샘플 전환 포함)가 이 구성을 지킵니다.
