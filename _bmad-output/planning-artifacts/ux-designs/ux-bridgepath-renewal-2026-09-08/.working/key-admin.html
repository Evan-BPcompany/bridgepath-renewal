"미확인" 점은 담당자가 아직 열람하지 않았다는 표시이며, 처리상태(예: 신규 접수)와는 별개의 값입니다. 상세 화면을 여는 것만으로 처리상태가 자동으로 바뀌지 않습니다 — 위 표의 두 번째 행(BP-20260909-018)처럼 "신규 접수" 상태이면서 동시에 "미확인"인 경우가 이 둘이 별개임을 보여주는 예시입니다.

PRD GAP "다음 행동 주체" 필드는 아직 PRD에 정식으로 포함되지 않은 UX 발견 데이터 요구사항입니다 — Architecture 전달 또는 PRD 보완이 필요한 항목으로 남아있습니다. 처리상태(FR-5.5, 10개 값)만으로는 지금 누가 행동해야 하는지 항상 판단할 수 없어(예: "추가정보 요청"은 고객 응답 대기일 수도, "공장 견적 확인 중"은 공장 회신 대기일 수도 있음) 이 목업에서 실험적으로 표시하고 있습니다.
처리상태 색상 그룹 범례 (10개 원 상태 → 6개 의미 그룹) 신규 — 신규 접수 진행 중 — 정보 확인 중 · 공장 견적 확인 중 · 정식견적 발송 응답·확인 대기 — 추가정보 요청 · 고객 검토 중 주의·보류 — 보류 완료·종료 — 진행 확정 · 종결 취소 — 취소 10개 처리상태를 색상마다 다르게 칠하지 않고, 의미가 같은 상태는 하나의 색으로 묶었습니다. "응답·확인 대기"는 문제 상황이 아니라 "다른 주체의 회신을 기다리는 중"이라는 뜻이라 경고색(주의·보류)과 다른 차분한 색을 사용합니다. "완료·종료" 그룹 안의 진행 확정 vs 종결은 같은 초록색을 쓰되 상태명 텍스트로 구분합니다.
