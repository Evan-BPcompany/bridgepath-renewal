- (note) 현재 상태: 순수 HTML/CSS/JS 정적 사이트, 서버·DB·로그인·견적 저장 기능 없음(견적 폼은 console.log만 함)
- (note) 현재 카테고리 4종: 선글라스, 일반 신발, 골프용품, 기타 주문제작(other-inquiry)
- (direction) 수리/AS 요청 서비스가 아니라 신규 제작(OEM/ODM) 견적 문의 서비스임을 재확인; 골프화·선글라스 제작 견적을 핵심으로 발전시킬 계획
- (direction) 기존 회사소개 콘텐츠는 유지 및 개선
- (direction) 향후 로그인, 견적현황, 제작현황, 마이페이지로 기능 확장 계획
- (decision) 기존 4개 카테고리의 유지/축소 여부는 이 브리프 단계에서 확정하지 않고 다음 PRD 단계로 넘김
- (note by user) 사용자는 현재 선글라스를 실제로 제작·판매 중인 상태 — 사이트가 프로토타입이 아니라 실사업 위에 얹히는 것
- (note) 참고사례 sinple.co.kr: AI 기반 신발 제조 플랫폼, 실시간 AI 견적, 로그인/마이페이지, 자재수급→생산중→검수중→배송중 생산현황 대시보드
- (note) 참고사례 shoedogkorea.com: 24년 경력 신발 제조사, 6단계 프로세스(샘플-견적-발주-생산-검수-출고) 안내형 랜딩페이지, 로그인/마이페이지 없이 단순 문의폼+전화/이메일
- (note by user) 참고사례 itaoptic43731.imweb.me(선글라스 특화, 봇 차단으로 자동 스캔 불가): 사용자가 마음에 든 점은 종류별 카테고리 및 소재별 설명 구성
- (note by user) 골프용품 카테고리는 참고할 만한 사이트를 찾기 어려웠다고 사용자가 언급
- (decision by user) 작업 방식은 Fast path 선택; 브리프 무게감은 개인/내부용(다음 PRD 작업을 위한 정리용)
- (note) 이번 작업 범위 제약: 기존 HTML/CSS/JS 수정·삭제·이름변경 없음, 기술스택 변경 없음, git commit/push 없음, 문서만 생성, 초보 개발자가 이해할 수 있게 작성
- (event) brief.md 초안 작성 완료: Executive Summary, Current State, Problem, Future Direction, Reference Cases, Who This Serves, Scope, Vision
- (event) addendum.md 작성 완료: 저장소 파일별 상세 인벤토리, 참고사이트 상세 노트(sinple/shoedog/선글라스사이트/골프 관찰), 작업 범위 제약 재확인
- (override by user) 사업모델 정정: Bridge Path는 중국 공장을 직접 보유·제조하지 않음. 실거래 경험이 있는 중국 제조업체·포워딩 파트너와 협력해 고객 OEM/ODM 의뢰(사양정리, 공장소통, 견적, 생산관리, 무역진행)를 지원하는 소싱/무역대행 모델임 — 이전 브리프의 '실제로 제조해온 경험' 표현을 대체
- (decision by user) 핵심 경험/초기 핵심 상품을 선글라스, 골프화, 나무 골프티 3종으로 확정. 그 외 일반 제품은 '기타 중국 OEM/ODM 문의'로 수용
- (decision by user) 기본 서비스 수수료: 중국 공장 EXW 가격의 8%. 중국 내륙운송비/국제운송비/검수비/통관비/관세·부가세는 실비로 별도 청구
- (decision by user) AI 견적은 확정가가 아닌 예상가격 범위 안내 기능으로 계획. 정식 견적은 공장·운송 조건 확인 후 담당자가 확정
- (decision by user) 사이트는 회사 PR과 편리한 제조·무역 의뢰 웹서비스라는 두 가지 목적을 가짐
- (decision by user) 확장 로드맵 세분화: 로그인, 견적현황, 샘플·제작현황, 출고·배송현황, 마이페이지
- (note) 환율 기준, 결제 시점, 최소 수수료, 검수 책임, 취소·환불 조건은 아직 미확정 — PRD 또는 운영정책 단계의 열린 질문으로 남김(이번 브리프 수정에서 확정하지 않음)
- (note) 작성 원칙: 공장을 직접 소유·직접 제조한다는 오해를 주는 표현 금지; 현재 구현된 기능과 향후 계획을 명확히 구분; brief.md/addendum.md만 수정, 코드·git 작업 없음
- (event) brief.md/addendum.md를 실제 사업모델(소싱·무역대행, 8% 수수료, AI 견적=예상범위 등)에 맞게 수정 완료
