# 인수인계: Watch 플러그인 설치 + 홈 디자인 학습 (2026-11-05 기준)

새 Claude 세션(데스크탑 등)이 `AGENTS.md`, 이 파일을 읽고 이어서 작업할 수 있게 정리한 문서입니다.
대화 내용은 넘어가지 않으니 맥락은 이 문서와 저장소(커밋 기록)에 있는 것이 전부입니다.

## 1. 오늘 한 일

- **claude-video(Watch) 플러그인을 이 노트북에 설치**하고 YouTube 영상 2개를 분석했습니다.
  - Watch는 영상 URL/로컬 파일을 받아 프레임+자막을 추출(로컬 엔진) 또는 Gemini에 통째로 보내(Gemini 엔진) 그 결과를 에이전트가 읽고 답하게 해주는 스킬입니다. `https://github.com/bradautomates/claude-video`
  - 설치물(전부 **이 노트북에만 로컬로 존재**, 저장소에는 없음):
    - Claude Desktop 마켓플레이스 `bradautomates/claude-video` + `watch` 플러그인
    - winget: FFmpeg, yt-dlp, Deno
    - `~/.config/watch/.env`에 개인 Gemini API 키 저장 (엔진: `gemini`)
  - Gemini 엔진이 그날 두 차례 503(서버 과부하)로 실패해서 두 영상 다 `--engine local`(프레임+자막 직접 추출)로 분석함.
- **영상에서 얻은 내용 두 가지:**
  1. (Nodi AI, "클로드 디자인 15분 가이드") 레퍼런스 사이트에서 "느낌"이 아니라 색상·폰트·간격 같은 실제 값을 추출해 디자인 시스템으로 만든 뒤 적용하는 워크플로.
  2. (Nodi AI, "클로드 디자인, 예쁘게 만들수록 망합니다") **"3초 테스트"** — 방문자가 3초 안에 핵심 메시지 하나를 파악해야 함(Duarte의 Glance Test). AI에게 "더 예쁘게/돋보이게"가 아니라 "이 디자인에 3초 테스트를 적용해서 핵심 메시지 하나를 먼저 보이게 하고, 장식/중복 요소는 비중을 낮춰줘. 필수 정보는 삭제하지 말고 강조 수준만 조정해줘"라고 요청하는 게 핵심.
- **홈 화면(`index.html`의 `.facts` 섹션)에 3초 테스트를 실험적으로 적용**했습니다. **커밋하지 않고 작업 트리에만 남겨뒀습니다** (`home.css`, `index.html` 수정 상태, `git status`에 unstaged로 보임).
  - Before: 통계 5개(제품종류/진행단계/상세견적기간/신발최소/골프최소)가 전부 같은 크기로 나열.
  - After(실험): "2~3 영업일"(상세견적 소요)을 크게 키워 헤드라인으로 내세우고, 나머지 4개는 삭제하지 않고 작은 보조 정보 줄로 내림. 새 클래스: `.facts-inner`, `.facts-headline`, `.num-lead`/`.unit-lead`, `.facts-support`. 관련 미디어쿼리(1100px, 520px 구간)도 같이 손댐.
  - 히어로 본문(질문 + 4개 선택지)은 이미 "질문 하나 → 보조 선택지" 구조라 손대지 않음.
- `docs/HANDOFF-2026-10-26.md`에서 다루던 레퍼런스 섹션(`.samples-grid`)은 이미 `sample-lead` 하나가 2x2로 커서 어느 정도 위계가 있다고 판단해 오늘은 건드리지 않음.
- 참고: 정적 서버 미리보기용 `.claude/launch.json`을 루트에 하나 새로 만듦 (`python -m http.server 8080`). 저장소에는 아직 커밋 안 된 상태(원하면 커밋해도 되는 파일, 비밀값 없음).

## 2. 다음에 할 일 (사용자가 데스크탑에서 이어감)

1. 데스크탑에 Watch 플러그인 재설치 — Claude Desktop → Customize → Plugins → Add marketplace → `https://github.com/bradautomates/claude-video` → Watch 설치 → 새 Code 세션 시작.
2. FFmpeg/yt-dlp/Deno 재설치:
   ```powershell
   winget install --id Gyan.FFmpeg --exact
   winget install --id yt-dlp.yt-dlp --exact
   winget install --id DenoLand.Deno --exact
   ```
3. Watch 첫 실행 시 설정 마법사에서 Gemini 선택 후 같은 Gemini API 키를 `~/.config/watch/.env`에 다시 입력(재발급 불필요).
4. `home.css`/`index.html`의 `.facts` 섹션 실험(위 1번 항목)을 데스크탑 화면에서 다시 확인하고, 마음에 들면 커밋, 아니면 `git checkout -- home.css index.html`로 되돌리기.
5. (선택) 로고 디자인 관련 영상은 아직 안 봄 — 다음 세션 주제 후보.

- 빌드 도구 없음, 정적 파일. `.claude/launch.json`의 `static-preview` 설정으로 `python -m http.server 8080` 띄우고 `http://localhost:8080/` 확인.
- 정책(변함없음): 수리/AS 사이트처럼 보이게 하지 말 것(신규 제작 OEM/ODM 견적 사이트). 회사소개/서비스 카드 재도입 금지.
