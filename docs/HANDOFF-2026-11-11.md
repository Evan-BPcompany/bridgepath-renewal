## 3. 먼저 확인할 것

1. **로고 키트 zip은 저장소에 그대로 둡니다 (결정 끝).** 사용자는 한 세션에서 "올리지 않기"를 골랐는데, 비슷한 시각에 다른 세션이 `4020fa3`로 이미 커밋·푸시했습니다. 이 사실을 알린 뒤 사용자가 "그대로 두기"를 골랐습니다. zip 안에는 로고 파일과 사용 안내서, 시안뿐이고 비밀정보는 없습니다. 빼거나 기록을 고치지 않습니다.
2. **`4020fa3`의 커밋 제목과 내용이 다릅니다.** "FINDER GREEN logo files"라고 되어 있지만 실제로 추가된 것은 예전 Bridge Path 로고(`assets/logo/logo-lockup*.png`, `logo-mark*.png`, `logo-wordmark.png`)이고, 어느 페이지도 쓰지 않습니다. 해가 되지는 않지만(서버와 `front:files`는 페이지가 쓰는 파일만 내보냄) 필요 없으면 지워도 됩니다.
3. **`.claude/skills/bmad-*` 파일 32개가 작업 폴더에서 지워진 상태입니다**(커밋 전, `git status`에 ` D`로 보임). 이 문서를 쓴 세션이 한 일이 아닙니다. 의도한 삭제인지 확인하기 전에는 커밋하거나 되돌리지 않습니다.

## 5. 확인 방법

- 화면 확인은 API 서버가 직접 내보내는 주소로 합니다: `npm run dev` 후 `http://localhost:4000/`. 서버는 시작할 때 내보낼 파일 목록을 정하므로, 로고나 페이지가 바뀌면 서버를 다시 시작해야 합니다.
- 정적 서버(예: `python -m http.server`)로 열면 화면은 보이지만 "예상 가격을 불러오지 못했어요"가 나옵니다. 주소가 달라 API가 요청을 막는 것(CORS)이고 버그가 아닙니다.
- 검증 명령은 `AGENTS.md`의 "검증 명령" 표 그대로입니다.
