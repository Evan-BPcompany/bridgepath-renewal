## 1. 랩탑에서 시작하기

필요한 것: Git, Node 20 이상(이 PC는 v24), Python 3(정적 서버용), Claude Code(데스크톱 앱).

1. 가져오기(처음이면 `clone`, 이미 있으면 `pull`):
   ```bash
   git clone https://github.com/Evan-BPcompany/bridgepath-renewal.git
   cd bridgepath-renewal
   git checkout develop/bmad-setup
   git pull
   npm install
   ```
2. 기준 확인: `npx jest`가 **전부 통과**해야 합니다(11-13 마감 시점 2,766개). 홈만 볼 때는 `npx jest --runInBand src/__tests__/web`.
3. 홈 화면 보기(빌드 없음): 저장소 폴더에서
   ```bash
   python -m http.server 8532 --directory .
   ```
   브라우저에서 `http://localhost:8532/index.html`. 서버를 껐다 켜면 예전 CSS가 캐시에 남을 수 있으니 강력 새로고침(`Ctrl+Shift+R`)을 합니다. (이 PC의 미리보기 설정은 저장소 밖 `F:\BPproject\.claude\launch.json`에 있어서 옮겨지지 않습니다.)
4. 견적 페이지(`sunglasses/shoes/golf-estimate.html`)에서 가격 범위를 보려면 **본서버**(`npm run dev`, 포트 4000)와 `.env`(`.env.example` 참고, DB 설정 포함)가 필요합니다. 본서버가 꺼져 있으면 브라우저 콘솔에 `ERR_CONNECTION_REFUSED`가 나는 것이 정상입니다(홈 자체의 오류가 아닙니다). 이 PC의 `.env`는 깃에 없어서 옮겨지지 않습니다.
5. **이미지를 새로 만들 때만** 필요한 것(지금은 급하지 않음):
   - `.env`에 `BAZE_API_KEY=...`(깃에 없음. 키 값은 채팅·메일·커밋에 붙이지 말고 비밀번호 관리자 등으로 옮기거나 `https://app.baze.co/dashboard/developers`에서 새로 받습니다).
   - 도구: `scrollcraft/baze.mjs`(Node만 있으면 됨). 먼저 `node scrollcraft/baze.mjs credits`로 잔액을 보고, 호출 전에 항상 `estimate`로 견적을 봅니다. **11-13 마감 시점 남은 크레딧은 2.3**이고 정지컷 한 장이 30이라, 새 이미지는 충전 후에 만듭니다.
   - 공통 프롬프트: `scrollcraft/art-direction.json`(`node scrollcraft/baze.mjs still <out.png> --art <장면> --model fal-ai/flux-2-pro --ar 4:3`). 웹용 변환에는 ffmpeg가 필요합니다(`winget install Gyan.FFmpeg`).
6. **Claude 스킬**은 사용자 전역(`~/.claude/skills`)이라 옮겨지지 않습니다. 이 PC에는 `hallmark`, `frontend-design`, `reference-led-design`, `impeccable`, `web-design-guidelines`, `scroll-craft`, `vercel-react-best-practices`가 있습니다. 코드와 테스트는 스킬 없이도 됩니다. 디자인 린트(`node ~/.claude/skills/hallmark/scripts/sloplint.mjs index.html home.css --genre editorial`, 기준은 **0 FAIL · 0 REFLEX · 0 WARN**)를 쓰려면 이 PC의 스킬 폴더를 랩탑 `~/.claude/skills/`로 복사하거나 Claude에게 설치를 요청합니다. impeccable의 엔진 바이너리는 내려받지 않기로 했습니다.
